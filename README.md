# Doughdog beta (web)

The built web version of Doughdog, published with GitHub Pages at
https://neiva603.github.io/doughdog-beta/

This repository holds only the compiled app, not the source code.
Built from Neiva603/pawket, commit `52b8ac4` (store build: no Plus, no developer tools).

## Install on an iPhone
Open the link in **Safari**, tap Share, then **Add to Home Screen**.
Your data stays on your phone.
